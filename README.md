# 信息流

一个极简的本地信息流应用：发布动态、按时间倒序浏览，数据只保存在你自己的浏览器里。

- 纯 HTML + 原生 CSS + 原生 JavaScript，零框架、零 CDN、零构建
- 全部代码合并在单个 `index.html` 中，双击即可运行
- 无后端、无账号，数据存放在浏览器 LocalStorage

## 功能

| 功能 | 说明 |
| --- | --- |
| 发布动态 | 顶部输入框填写文本，点击「发布」新增一条 |
| 作者昵称 | 发布时可填写昵称（最多 20 字），留空显示「匿名用户」 |
| 头像 | 内置 5 款 SVG 头像供单选，选中状态随动态保存 |
| 发布地点 | 浏览器定位后自动匹配城市名，获取失败则该条不显示地点 |
| 信息流展示 | 所有动态按发布时间倒序排列，最新在最上 |
| 本地持久化 | 刷新页面、重启浏览器后数据仍在 |
| 单条展示 | 显示头像、昵称、发布时间、地点（有则显示）与文本内容 |

## 不做的功能

为保证最小可用，以下均**未实现**：评论、点赞、删除、图片上传、用户登录、深色模式、分页、分享、搜索、话题标签。

## 运行方式

直接双击 `index.html`，或拖入浏览器窗口打开。无需安装依赖、无需启动服务。

## 数据结构

存储键：`localStorage['feed_posts_v1']`，值为 JSON 数组，每个元素：

```json
{
  "id": "lq3k9f_8x2b1c",
  "content": "今天的第一条动态",
  "createdAt": 1763000000000,
  "author": "林一",
  "avatar": 2,
  "location": "上海"
}
```

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | string | 唯一标识，由时间戳与随机串拼接 |
| `content` | string | 动态正文（已去除首尾空白） |
| `createdAt` | number | 毫秒时间戳，用于倒序排序与展示格式化 |
| `author` | string | 昵称，读取时归一化，空值回落为「匿名用户」 |
| `avatar` | number | 头像索引 0~4，非法值回落为 0 |
| `location` | string \| null | 城市名，`null` 表示未获取到，渲染时不显示 |

`author` / `avatar` / `location` 为后加的可选字段：旧数据缺少这些字段时，读取阶段统一补默认值，不需要迁移存储键。

## 头像与定位说明

- **头像**：5 款几何风格头像以内联 `<svg><symbol>` 精灵图内置在页面里，不使用任何图片文件或外链；发布区用原生 radio 单选，选择结果只保存索引值。
- **地点**：页面加载后通过 `navigator.geolocation` 请求定位（需用户授权），拿到经纬度后与内置的城市坐标表做 Haversine 最近距离匹配，200km 内命中即显示城市名，例如「上海」。
- **降级策略**：拒绝授权、超时（8 秒）、`file://` 下被浏览器限制或坐标超出所有已知城市范围时，该条动态不显示地点，页面其余功能不受影响。
- **近似性**：坐标表只覆盖主要城市，县级地区会显示邻近的大中城市名；这是零外链约束下的取舍。定位结果不写入 LocalStorage，只随单条动态保存城市名，不保存原始经纬度。

键名带 `v1` 版本号，便于日后结构演进时平滑迁移。

## 健壮性

- 读取与写入 LocalStorage 均由 `try / catch` 包裹，解析失败或存储被禁用时降级为空列表，不会抛出错误。
- 解析后逐条校验字段类型，自动过滤损坏数据，并为缺失的昵称 / 头像 / 地点字段补默认值。
- 写入失败（如隐私模式、配额超限）时页面顶部显示提示条，内容在本次会话内仍可正常查看。
- 用户文本统一通过 `textContent` 写入，不使用 `innerHTML` 拼接，避免标签注入；定位全程异常捕获，失败仅降级不报错。

## 浏览器兼容

支持 Chrome、Edge、Firefox、Safari 等现代浏览器。`file://` 方式打开时部分浏览器对 LocalStorage 有限制，若顶部出现降级提示，可改用本地静态服务打开：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```
